CSS Aural

Aural CSS was designed to control how web content is presented through speech synthesizers and screen readers.

🔊

Volume

Controls speech volume.

◉

Voice

Controls voice characteristics.

◷

Pause

Controls pauses during speech.

Aural Properties

Property Description Example
volume Controls speech volume. volume: loud;
voice-family Specifies the voice family. voice-family: male;
speech-rate Controls speech speed. speech-rate: fast;
pause-before Adds a pause before speaking. pause-before: 2s;
pause-after Adds a pause after speaking. pause-after: 2s;

Note: Many traditional aural CSS properties are now obsolete or have limited browser support.
