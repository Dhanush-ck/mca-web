CSS Default Values

CSS properties have default values that browsers use when a value is not explicitly specified.

1

Opacity

Default opacity is completely visible.


opacity: 1
S

Position

Elements are positioned statically by default.


position: static
V

Visibility

Elements are visible by default.


visibility: visible

Default Values

Property Default Value Description
position static Default positioning method.
opacity 1 Element is completely opaque.
visibility visible Element is visible.
overflow visible Overflowing content remains visible.
font-style normal Text is not italic.
font-weight normal Normal font thickness.
