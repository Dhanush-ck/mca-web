CSS Selectors

Selectors identify the HTML elements that CSS rules should be applied to.

*

Universal

Selects every element.


* { }
.

Class

Selects elements by class.


.box { }
#

ID

Selects an element by ID.


#header { }

Selector Types

Selector Name Example
* Universal * { margin: 0; }
p Element p { color: red; }
.box Class .box { padding: 10px; }
#header ID #header { height: 80px; }
div p Descendant div p { color: blue; }
div > p Child div > p { color: green; }
a:hover Pseudo-class a:hover { color: red; }
