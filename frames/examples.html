PRACTICAL EXAMPLES

Frame Examples

The following examples demonstrate how frames and iframes can be used to divide a webpage and display different HTML documents.

1

Old Frame Layout

The traditional method used a frameset to divide the browser window into multiple frames. 

<frameset cols="20%,80%">
    <frame src="menu.html">
    <frame src="home.html">
</frameset>
Divides the window into 20% and 80% sections.
2

Modern Iframe

An iframe can embed another HTML document inside a normal webpage. 

<iframe
    src="home.html"
    name="content">
</iframe>
Displays home.html inside the iframe.
3

Target Attribute

The target attribute specifies where the linked webpage should be displayed. 

<a href="about.html"
   target="content">
    About Frames
</a>
Opens about.html inside the content iframe.
4

20 : 80 Layout

CSS can be used to create the required menu and content layout using percentage widths. 

.menu-frame {
    width: 20%;
}

.content-frame {
    width: 80%;
}
Menu occupies 20% and content occupies 80%.
5

Complete Navigation

Combining an iframe with the target attribute allows a navigation menu to control the content displayed in another frame. 

<iframe
    src="menu.html"
    class="menu-frame">
</iframe>

<iframe
    src="home.html"
    name="content"
    class="content-frame">
</iframe>
The menu remains on the left while the selected webpage opens in the 80% content area.
