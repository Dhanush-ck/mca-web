Client/Server Web Application
Client

A client is a device or application that requests services or resources from a server over a network. When a user enters a website address in a browser, the browser acts as a client and sends a request to the web server.

  • Web browsers such as Chrome, Firefox and Edge
  • Mobile applications
  • Desktop applications
Server

A server is a computer or software system that provides services, data, or resources to clients over a network. A web server receives requests from clients and sends the requested web pages or other resources as responses.

  • When you visit a website, your browser sends a request to the website's server, and the server sends the webpage back.
