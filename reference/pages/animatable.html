CSS Animatable

Animatable properties can smoothly change their values when used with transitions or animations.

↔

Width

Width can transition smoothly.


width: 300px;
◐

Opacity

Controls transparency.


opacity: .5;
↻

Transform

Allows smooth transformations.


transform: rotate(45deg);

Animatable Properties

Property Animatable Example
color Yes color: red;
background-color Yes background-color: blue;
width Yes width: 300px;
height Yes height: 200px;
opacity Yes opacity: 0.5;
transform Yes transform: scale(1.2);
margin Yes margin: 20px;
