Client & Server

Client

A client is a device or application that requests services or resources from a server over a network. When a user enters a website address in a browser, the browser acts as a client and sends a request to the web server.

  • Web browsers such as Chrome, Firefox and Edge
  • Mobile applications
  • Desktop applications

Server

A server is a computer or software system that provides services, data, or resources to clients over a network. A web server receives requests from clients and sends the requested web pages or other resources as responses.

  • Receives requests from clients
  • Processes the requested information
  • Sends the requested resources as a response

Components of Web Application

View Layer

The View Layer is the part of an application that the user sees and interacts with. It is responsible for displaying information and collecting user input.

Technologies: HTML, CSS and JavaScript.

Examples: Forms, buttons, menus and webpage layouts.

Business Layer

The Business Layer contains the application's logic and rules. It processes user requests and determines what should happen based on the application's requirements.

Example: Checking whether a username and password are correct during login.

Data Access Layer

The Data Access Layer is responsible for communicating with databases or other data storage systems. It retrieves, adds, updates, or deletes data.

Example: Retrieving a user's profile information from a database.

HTTP and HTTP Request

Definition of HTTP

HTTP stands for HyperText Transfer Protocol. It is a communication protocol used to transfer resources between a client and a web server.

HTTP Request and Response

An HTTP request is a message sent by the client to the server asking for a resource or requesting an action.

GET - Request data POST - Send data PUT - Update data DELETE - Delete data QUERY - Search/Query data

An HTTP response is the message sent by the server back to the client. It contains:

Status code Headers Requested content
