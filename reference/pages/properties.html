CSS properties define how HTML elements look, behave and are positioned on a webpage.

Common Properties

Property Description Example
color Sets the text color. color: red;
background-color Sets the background color. background-color: blue;
font-size Sets the text size. font-size: 20px;
margin Sets outside spacing. margin: 20px;
padding Sets inside spacing. padding: 20px;
border Creates a border around an element. border: 1px solid;
width Controls element width. width: 300px;
height Controls element height. height: 200px;
