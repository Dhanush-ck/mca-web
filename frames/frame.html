HTML FRAMES

About Frames

Frames allow different HTML documents to be displayed in separate sections of a webpage. HTML has traditionally provided frames using the <frame> element, while modern webpages use the <iframe> element for embedding content.

OLD METHOD

<frame> and <frameset>

In older versions of HTML, the <frameset> element was used to divide the browser window into multiple sections. Each section was created using a <frame> element.

A separate HTML document could be loaded into each frame. The size of the frames could be specified using rows or columns. 

<frameset cols="20%,80%">
    <frame src="menu.html">
    <frame src="home.html" name="content">
</frameset>

The menu frame could then use the target attribute to open pages in the content frame. 

<a href="about.html" target="content">
    About Frames
</a>
MODERN METHOD

<iframe>

The <iframe> element is the modern way to embed another HTML document inside a webpage. Unlike the old <frame> element, an iframe can be placed inside the normal HTML <body>.

CSS can be used to control its size, position, layout, and responsiveness. 

<div class="container">

    <iframe src="menu.html"
            class="menu-frame">
    </iframe>

    <iframe src="home.html"
            name="content"
            class="content-frame">
    </iframe>

</div>

A link can load its webpage inside the iframe using the target attribute. 

<a href="about.html"
   target="content">
    About Frames
</a>

In this project: The modern <iframe> element is used to create the menu and content areas. The menu occupies 20% of the page, while the content area occupies 80%. The target attribute loads the selected page inside the content iframe.
