Common Functions

Function Purpose Example
calc() Performs calculations. width: calc(100% - 20px);
rgb() Creates an RGB color. rgb(255, 0, 0)
rgba() Creates an RGB color with transparency. rgba(255,0,0,.5)
hsl() Creates an HSL color. hsl(240,100%,50%)
var() Uses a CSS variable. var(--main-color)
min() Returns the smallest value. min(90%,500px)
max() Returns the largest value. max(50%,300px)
