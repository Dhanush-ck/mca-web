CSS Colors

CSS provides several ways to define colors, including names, hexadecimal, RGB and HSL values.

#

RGB

HSL

Uses hue, saturation and lightness.


hsl(239,84%,67%)

Color Formats

Format Description Example
Color Name Uses predefined color names. red
HEX Uses hexadecimal values. #ff0000
RGB Uses red, green and blue values. rgb(255,0,0)
RGBA RGB with transparency. rgba(255,0,0,.5)
HSL Uses hue, saturation and lightness. hsl(0,100%,50%)
HSLA HSL with transparency. hsla(0,100%,50%,.5)
