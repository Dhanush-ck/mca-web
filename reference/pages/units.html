CSS Units

CSS units define measurements for properties such as width, height, spacing and font size.

px

Pixels

A commonly used fixed unit.


20px
%

Percentage

Relative to a parent or reference value.


50%
rem

REM

Relative to the root font size.


2rem

Common CSS Units

Unit Type Description Example
px Absolute Pixels. 20px
% Relative Percentage value. 50%
em Relative Relative to element font size. 2em
rem Relative Relative to root font size. 2rem
vw Relative Relative to viewport width. 50vw
vh Relative Relative to viewport height. 50vh
